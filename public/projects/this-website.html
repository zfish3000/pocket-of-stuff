This Website

This website is my sorta portfolio sorta personal website just to show off stuff i've done. This is how it works.

The Main Page

The Main Page is clearly the coolest most amazing website page ever in the history of the internet. It works by turning all the projects in a projects folder into the blocks. When the website opens, it arranges the blocks, and turns on gravity. It simulates the blocks using a library called Matter.js. The rebuild button just turns off physics and resets their positions. Each of the blocks color, shape, and title, are determined by the actual projects pages from the projects folder. Speaking of the project pages...

The Project Pages

Each Project gets its own page. It a really simple and standard webpage. It uses simple HTML and CSS, and not much else. The only special thing about the project page is metadata. Metadata is data about data. How meta. Thats why it's called metadata. Anyway, the metadata in all websites does stuff like providing data to your browser, scaling the webpage to your screen, or the author of the page. You can also make custom metadata. In the project pages, I added custom metadata that controlls the color and the block shape. This is what the main page pulls from to make the blocks. All of the project pages are just copies of a template that I edit to add content. So yeah, that's how this website works.
